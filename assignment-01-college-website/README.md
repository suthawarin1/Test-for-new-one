# Assignment 01 — College Website

**รายวิชา:** 21901-2012 การพัฒนาระบบร่วมกันด้วยแพลตฟอร์ม  
**โจทย์:** ร่วมกันพัฒนาเว็บไซต์แนะนำวิทยาลัย 4 หน้า โดยใช้ AI ช่วยสร้างเนื้อหาและโค้ด พร้อมฝึก GitHub Collaboration

## โครงสร้างไฟล์
- `index.html` — หน้าหลัก
- `departments.html` — หน้าแนะนำสาขา
- `activities.html` — หน้ากิจกรรม
- `contact.html` — หน้าติดต่อ
- `style.css` — รูปแบบกลาง ใช้ร่วมกันทุกหน้า

## แบ่งหน้าที่ (กลุ่มละ 4 คน)
| สมาชิก | Branch | ไฟล์ที่รับผิดชอบ |
|---|---|---|
| คนที่ 1 | `feature/home` | `index.html` |
| คนที่ 2 | `feature/departments` | `departments.html` |
| คนที่ 3 | `feature/activities` | `activities.html` |
| คนที่ 4 | `feature/contact` | `contact.html` |

## วิธีเริ่มต้นสำหรับครู
1. สร้าง GitHub Repository ชื่อ `assignment-01-college-website` (หรือเพิ่มชื่อกลุ่มต่อท้าย)
2. อัปโหลดไฟล์ทั้งหมด **จากภายในโฟลเดอร์นี้** ไปยังรากของ Repository เพื่อให้ `index.html` อยู่ที่ระดับบนสุด
3. เชิญสมาชิกในกลุ่มเข้าร่วม Repository และกำหนดสิทธิ์ให้เหมาะสม
4. ให้แต่ละคนสร้าง Branch จาก `main` และแก้เฉพาะไฟล์ที่รับผิดชอบ
5. นักเรียน Commit, เปิด Pull Request และให้เพื่อนตรวจสอบก่อน Merge เข้า `main`
6. เปิด Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save เพื่อเผยแพร่เว็บ

## กติกา
- ห้ามเปลี่ยนชื่อไฟล์และลบเมนูนำทาง
- ยังไม่แก้ `style.css` กลางโดยไม่ตกลงกับทีม
- ห้ามใส่ข้อมูลส่วนตัว เบอร์โทร หรือภาพบุคคลโดยไม่ได้รับอนุญาต
- ตรวจสอบความถูกต้องของโค้ดและเนื้อหาที่ AI สร้างก่อนส่งงาน
- สมาชิกทุกคนต้องมี Commit และ Pull Request ของตนเอง

## สิ่งที่ต้องส่ง
1. ลิงก์ Google Docs ที่ใช้วางแผน
2. ลิงก์ GitHub Repository
3. หลักฐาน Commit และ Pull Request ของสมาชิกทุกคน
4. ลิงก์เว็บไซต์ที่เปิดได้และเมนูเชื่อมกันครบทั้ง 4 หน้า

## Prompt ตัวอย่าง
> ช่วยพัฒนาเฉพาะไฟล์ [ชื่อไฟล์] ของเว็บไซต์แนะนำวิทยาลัยโดยใช้ HTML และ CSS ให้ดูทันสมัย อ่านง่าย และรองรับมือถือ โดยต้องรักษาเมนูเชื่อม 4 หน้า ใช้ `style.css` กลาง ห้ามเปลี่ยนชื่อไฟล์หรือแก้ไฟล์ของสมาชิกอื่น และสรุปสิ่งที่แก้ไขเพื่อใช้เป็นข้อความ Commit
